# Chinese-teacher---RAG
一个语文教师私有知识库 RAG 系统

面向初高中语文老师的私有文档 RAG 系统，
核心目标：基于教师课堂沉淀私有文档，完成备课、出题、答疑、错题沉淀闭环。



### 1. 私有知识库（最高优先级，教师课堂沉淀）

文档类型：课堂教案、课堂实录笔记、学生错题集、学生作答样本、课堂学生奇思互动记录、自制讲义
标签维度：学段、单元、篇目、知识点、文档类型、学情标签（班级共性错误、易混淆点）
切片规则：

- 教案 / 讲义：按课时、教学环节（导入、重难点、课堂问题、拓展）切片
- 错题 & 学生作答：单道题目 + 学生错误答案 + 教师批注为最小单元，保留错误原因与点评
- 文言笔记：以单个实词 / 虚词、特殊句式切片
- 作文材料：按主题、学生立意（偏题 / 平庸 / 深刻）拆分

### 2. 公共基准库（兜底补充）

部编初高中语文教材、课文原文、注释、官方教参、历年语文真题、作文素材、文学常识、文言实词虚词库、优质课案例；
拓展原著：《论语》《道德经》《古文观止》《世说新语》《史记》《资治通鉴》。


优先检索个人课堂沉淀资料（往年教案、课堂笔记、学生错题、学生作答样本、课堂互动记录），部编教材 / 课标 / 古籍等公共知识库作为兜底补充；保持老师个人教学风格，复用过往课堂案例、话术，每次教学产生新资料可入库持续迭代知识库。

两套向量库隔离，检索优先级：**私有知识库 > 公共基准库**

1. 检索优先召回私有知识库文档，私有资料不足时，才调用公共基准库补充；
2. 输出内容优先沿用教师过往课堂表述、例题、话术，对齐个人教学风格；
3. 引用内容标注来源，区分【私有知识库】/【公共基准库】；
4. 若私有文档存在内容冲突，**以教师手写批注版本优先级最高**；
5. 学生答疑场景强制约束：启发式提问引导思考，禁止直接输出完整答案。



1. **针对性备课**：检索历史同篇目教案、课堂记录、往届学生易错点，迭代生成新版教案、板书、课堂预设问题，预判学生误区。
2. **定制化出题**：从私有错题库提取学生高频错误，选择题干扰项采用学生真实错答案例；对照课标校验，输出试题、答案、评分细则 + 命题说明。
3. **启发式答疑**
   - 教师端教研答疑：调取过往课堂案例、批注、学生疑问，辅助教研；
   - 学生端答疑：启发式引导，不直接输出完整标准答案。
4. **知识库闭环沉淀**：新课、批改作业后，新增课堂笔记、新错题、课堂疑问上传入库，持续扩充向量库，越使用越贴合本班学情。
